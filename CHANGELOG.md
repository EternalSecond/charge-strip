# Changelog

## 0.5.1

- Use the Windows notification area for all system tray display modes. Removed the floating Charge button.
- Added a battery icon with an optional numeric mode.

## 0.5.0

- Added a compact, draggable Charge button next to the system tray.
- The button opens the existing battery flyout. The numeric icon remains available as a tray-only option.

## 0.4.0

- Replaced the floating strip with a battery percentage icon in the Windows system tray.
- Added a click-to-open battery list and a live tray preview in Settings.
- Preserved device order, visibility, language, appearance colors, and startup preferences.

## 0.3.1

- Refreshed the portable ZIP with the English Settings screenshot and current documentation.

## 0.3.0

- Added a language selector for Ukrainian, Russian, and English in Settings.
- Localized the editor, tray and battery menus, device labels, and charge statuses.
- Saved the selected language with the other preferences.

## 0.2.1

- Added a documented, one-command build for the portable ZIP and its SHA-256 checksum.
- Updated the installation, upgrade and device compatibility documentation.

## 0.2.0

- Added battery and charging readings for the HyperX Pulsefire Haste 2 Wireless.
- Added device visibility, order, limit and display modes.
- Added a dark Settings window with live preview.

## 0.1.0

- Added a configurable battery overlay with SteelSeries Arctis Nova Pro Wireless headset and base-slot readings.
- Added separate normal and Settings launch modes, startup registration and per-user settings.
